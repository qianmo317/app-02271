# 设计规范 — 蜜语甜心 Sweet Whisper Bakery

## 1. 色彩体系

### 主色

| 名称 | 色值 | 用途 |
|------|------|------|
| 品牌主色 | `#d4a574` | 按钮、导航高亮、标签、链接悬浮 |
| 主色深色 | `#c49664` | 按钮 hover、主色变体 |
| 主色浅色 | `#f5e6d3` | 背景色、选中态 |
| 暖白背景 | `#faf8f5` | 区域分隔背景 |

### 辅助色

| 名称 | 色值 | 用途 |
|------|------|------|
| 价格红 | `#e74c3c` | 价格、促销信息 |
| 成功绿 | `#67c23a` | 服务保障图标、免配送费标识 |
| 深灰底 | `#2c2c2c` | Footer 背景、特色展示区 |

### 文字色

| 层级 | 色值 | 用途 |
|------|------|------|
| 标题 | `#333333` | 一级标题、产品名称 |
| 正文 | `#666666` | 描述文字、段落内容 |
| 辅助 | `#999999` | 二级信息、标签、销量 |
| 占位 | `#cccccc` | 原价删除线、占位文字 |

## 2. 字体方案

| 用途 | 字体 | 备注 |
|------|------|------|
| 标题/品牌 | `Noto Serif SC` | 衬线体，传递高端、精致感 |
| 正文/UI | `Noto Sans SC` | 无衬线体，清晰易读 |
| 降级方案 | `-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Arial` | 系统字体回退 |

## 6. 组件规范

### 导航栏 (AppHeader)

- 高度：桌面 70px / 移动 60px
- 背景：`rgba(255,255,255,0.95)` + `backdrop-filter: blur(20px)`
- 固定定位，滚动后增加阴影
- Logo：品牌图标 + 衬线字体 22px
- 搜索框：200px 宽，圆角 20px

### 产品卡片 (ProductCard)

- 圆角 16px，图片区域 `aspect-ratio: 1`
- 悬浮：卡片 `translateY(-6px)`，图片 `scale(1.08)`
- 底部渐变遮罩出现"加入购物车"按钮
- 左上角标签（招牌/新品/人气等）
- 底部：价格（红色 20px）+ 评分 + 销量

### 轮播横幅 (HeroBanner)

- 高度：桌面 560px / 移动 400px
- 渐变遮罩：`linear-gradient(135deg, rgba(0,0,0,0.55), rgba(0,0,0,0.2))`
- 标题：白色 48px 衬线体，文字阴影
- 指示器：横条式，激活态宽 50px，品牌色

### 页脚 (AppFooter)

- 背景：`#2c2c2c`
- 4 列网格：品牌信息 / 快速链接 / 产品分类 / 联系方式
- 底部分割线 + 版权信息

## 7. 响应式断点

| 断点 | 规则 |
|------|------|
| 桌面端 | > 1024px：4 列产品网格 |
| 平板端 | 769-1024px：3 列产品网格 |
| 移动端 | ≤ 768px：2 列产品网格，隐藏搜索栏，抽屉菜单 |

## 8. 动效规范

| 场景 | 类型 | 参数 |
|------|------|------|
| 路由切换 | fade | `opacity 0.3s ease` |
| 卡片悬浮 | transform + shadow | `0.4s cubic-bezier(0.25,0.46,0.45,0.94)` |
| 导航下划线 | width | `0.3s ease` |
| 图片缩放 | transform | `0.6s ease` |
| 导航链接色 | color | `0.3s ease` |
| 遮罩层出现 | opacity + translateY | `0.3s ease` |

## 9. Element Plus 主题定制

通过 CSS 变量覆盖 Element Plus 默认主题：

```css
:root {
  --el-color-primary: #d4a574;
  --el-color-primary-light-3: #e0bb94;
  --el-color-primary-light-5: #e9ccaa;
  --el-color-primary-light-7: #f2ddc4;
  --el-color-primary-light-8: #f5e6d3;
  --el-color-primary-light-9: #faf2e9;
  --el-color-primary-dark-2: #c49664;
}
```

滚动条：品牌色 `#d4a574`，宽 8px，圆角 4px。
文字选中：品牌色背景 + 白色文字。
